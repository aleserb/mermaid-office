Mermaid Office support

Create and edit Mermaid diagrams in Microsoft Word. Rendering happens locally; documents contain PNG pictures that recipients can view without the add-in. Mermaid Office is free, open-source software published by Aleksandr Serbin (aleserb).

Get help or report a problem

Open a support issue or browse existing issues. Include your Word platform and version, browser if applicable, the steps to reproduce the problem, and a minimal non-sensitive example.

Submitting an issue requires a GitHub account. The tracker is public: do not upload private documents, credentials, personal information, or confidential diagram source. Redact screenshots and logs. Support is best-effort, with no guaranteed response time.

Requirements and installation

The add-in targets modern Word on the web, Windows, and macOS with WordApi 1.4 and ImageCoercion 1.1. The separate settings window requires DialogApi 1.2. An internet connection is normally needed to load the hosted app and Office.js; fully offline installation is not provided. No separate Mermaid Office account, subscription, or rendering server is required.

Availability of add-ins depends on your Office version and organization policy. For developer sideloading and deployment information, see the project README and Microsoft's sideloading instructions. A published Marketplace installation link will be added here after approval.

Using the add-in

  1. Open Insert > Mermaid in Word to show the editor pane.
  2. Place the cursor on a blank line, enter valid Mermaid code, and choose Insert.
  3. Select an existing Mermaid picture to load its source. Small diagrams update after a typing pause; large diagrams require the Update button.
  4. Use the gear for theme, layout, typography, and image quality. Apply saves the selected settings and any pending source edits.

The document-info icon opens the Mermaid syntax reference. Errors below the editor prevent changes to the last valid picture.

Common issues

  • Word shows a loading dialog: larger picture imports can trigger Word's own progress UI. Use Auto or Standard quality and explicit Update for large diagrams.
  • Update is disabled: there may be no unsaved changes, invalid source, a render or Word operation in progress, or a pending selection decision. Resolve the message in the pane first.
  • Settings will not open: allow Office's dialog request and check your Office version and network access. The pane displays opening errors.
  • Copied pictures are no longer editable: some paste paths and image tools remove embedded source metadata. Keep the original document or a separate copy of the Mermaid source.
  • An update is not visible: close and reopen the pane. Sideloaded manifest changes may require removing and uploading the manifest again.
